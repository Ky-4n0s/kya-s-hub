    *(รวมอัปโหลดและตั้งค่าลายน้ำในระบบ)
  • 3฿ : สร้าง 1 โฟลเดอร์ (พร้อมใส่คำอธิบาย)

  • 5฿ : ลงโค้ด CSS เหมาทุกหน้า (Global)
    *(คลุมธีมสีเดียวกันทั้งหมด แยกสีรายตัวไม่ได้)
  • +20฿ ขึ้นไป : ปรับแต่ง/เขียนโค้ดเพิ่ม
    *(เช่น เพิ่มกล่องข้อมูล ประเมินราคาก่อนทำได้ค่ะ)
  • +20฿ : ใส่ Profile Warning
  • +10฿ : ใส่ Character Warning
