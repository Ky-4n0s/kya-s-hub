บริการรายตัว (A la carte)
จัดการข้อมูล & อัปโหลด
  • 5฿ : สร้างหน้าตัวละคร (ตั้งชื่อ + ใส่เครดิต)
  • 1฿ : อัปโหลดรูปภาพ (ได้ 2 รูป)
    *(ภาพเดียวกันแต่มีเวอร์ชันพื้นขาว/พื้นใส นับเป็น 1 รูปค่ะ แฟร์ๆ เลย!)
  • +2฿ : บริการรีไซส์ภาพ / 1 รูป
    *(กรณีไฟล์ภาพใหญ่เกิน 4MB หรือ 4000px)
  • 10฿ : ใส่ลายน้ำ (Watermark) เหมาต่อครั้ง
    *(รวมอัปโหลดและตั้งค่าลายน้ำในระบบเป็นค่าเริ่มต้นสำหรับครั้งถัดไป)
  • 3฿ : สร้าง 1 โฟลเดอร์ (พร้อมใส่คำอธิบาย)
  • 1฿ : สร้าง 1 Tab / 1 Tag
ตกแต่งโปรไฟล์ (HTML/CSS)
  • 20฿ : ลงโค้ด HTML เริ่มต้น / 1 ตัวละคร
  • 10฿ : ลงโค้ด CSS รายตัว
    *(ปรับแต่งสีให้เข้ากับธีมของคาแรคเตอร์นั้นๆ ฟรี)
  • 5฿ : ลงโค้ด CSS เหมาทุกหน้า (Global)
    *(เป็นการคลุมธีมสีเดียวกันทั้งหมด ไม่สามารถแยกสีรายตัวได้)
  • +20฿ ขึ้นไป : ปรับแต่ง/เขียนโค้ดเพิ่มจากต้นฉบับ
    *(เช่น ต้องการเพิ่มกล่องใส่ข้อมูลประวัติ/ข้อมูลอดอปต์ คิดราคาตามความยากง่าย ประเมินราคาก่อนทำได้ค่ะ)
  • +20฿ : ใส่ Profile Warning (คำเตือนหน้าหลัก)
  • +10฿ : ใส่ Character Warning (คำเตือนรายตัว)
แพ็กเกจเหมาจัดบ้าน (Account Makeover)
Fée
1 - 10 ตัวละคร (เริ่มต้น 50 - 80฿) คลิกเพื่อดูรายละเอียด
  • สร้างโฟลเดอร์: สูงสุด 3 โฟลเดอร์หลัก (ไม่สามารถสร้างซับโฟลเดอร์ได้)
  • จัดระเบียบ: ย้ายตัวละครเข้าโฟลเดอร์ให้เป็นระเบียบ
  • ติดแท็ก (Tag): สร้างระบบแท็กพื้นฐานเพื่อให้ค้นหาง่ายขึ้น
  • ลายน้ำ (Watermark): บริการตั้งค่าลายน้ำ Global ในระบบ
  • ระยะเวลาดำเนินการ: 1-2 วัน
Nymphe
11 - 25 ตัวละคร (100 - 150฿) คลิกเพื่อดูรายละเอียด
  • สร้างโฟลเดอร์: หลักและย่อยรวมกันสูงสุด 8 โฟลเดอร์
  • จัดระเบียบ: ย้ายตัวละครเข้าโฟลเดอร์ตามหมวดหมู่
  • ระบบแท็ก: ติดแท็กแบบละเอียด (เช่น สายพันธุ์, สถานะ Trade/Sell)
  • ลายน้ำ (Watermark): บริการตั้งค่าลายน้ำ Global ในระบบ
  • ระยะเวลาดำเนินการ: 2-3 วัน
Clairière
26 - 50 ตัวละคร (200 - 250฿) คลิกเพื่อดูรายละเอียด
  • สร้างโฟลเดอร์: หลักและย่อยรวมกันสูงสุด 15 โฟลเดอร์
  • จัดระเบียบ: ย้ายตัวละคร + จัดระบบแท็กแบบเต็มรูปแบบ
  • ลายน้ำ (Watermark): บริการตั้งค่าลายน้ำ Global ในระบบ
  • แถมฟรี! ตกแต่งโค้ดหน้าแรก (User Profile) ด้วย HTML 1 หน้า
  • ระยะเวลาดำเนินการ: 3-5 วัน
Forêt
51 - 100 ตัวละคร (350 - 450฿) คลิกเพื่อดูรายละเอียด
  • สร้างโฟลเดอร์: สร้างและจัดหมวดหมู่ได้แบบ ไม่จำกัดจำนวน
  • จัดระเบียบครบวงจร: จัดการย้ายตัวละคร จัดหน้า Directory แท็ก และลายน้ำภาพรวม
  • แถมฟรี! ตกแต่งหน้าแรก (User Profile) ด้วย HTML
  • ระยะเวลาดำเนินการ: 5-7 วัน
Royaume
100+ ตัวละคร (เริ่มต้น 500฿) คลิกเพื่อดูรายละเอียด
  • แพ็กเกจสเกลใหญ่สุด: บริการทุกอย่างเหมือนแพ็กเกจ Forêt (ไม่จำกัดโฟลเดอร์/จัดระเบียบ/ลายน้ำ/แถม HTML หน้าแรก)
  • การคิดราคาเพิ่ม: กรณีมีตัวละครเกิน 100 ตัวแรก ขออนุญาตคิดบวกเพิ่มตัวละ 2-3 บาทค่ะ
  • ระยะเวลาดำเนินการ: 7-10 วัน (ขึ้นอยู่กับจำนวนจริง)
